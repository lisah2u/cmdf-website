## Site Navigation Flow

**Primary User Paths:**
1. **Prospective Students/Families:** Home → Programs → Get Involved → Join The Band
2. **Donors:** Home → Support → Donate → Recognition
3. **Volunteers:** Home → Get Involved → Volunteer Opportunities
4. **General Public:** Home → About → Mission → Events

**Content Hierarchy:**
- **Level 1:** Main navigation sections (5 primary areas)
- **Level 2:** Sub-sections and program details
- **Level 3:** Specific information pages and forms
- **Cross-cutting:** Contact info, social media, and impact metrics appear throughout

**Mobile Considerations:**
- Hamburger menu likely for mobile navigation
- Key metrics prominently displayed
- Donation CTAs accessible from all pages
- Contact information easily accessible
